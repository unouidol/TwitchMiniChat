Twitch Minichat is a lightweight app that allows interaction with twitch via IRC, supporting multi-account both for the chat session and for the PokemonCommunityGame (PCG) extension.
In one app you can log and navigate through multiple accounts, interact with separate channel chats and play with the PCG extension without opening multiple browser session!
It now supports automatic missing Pokémon dex list and can send alerts when a missing Pokémon spawns!
