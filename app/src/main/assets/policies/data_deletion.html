Data Deletion Request

Last updated: 2026-05-06

You can request deletion of TwitchMiniChat app-related data associated with your use of the app. You can also remove some data directly from the app in Safety & Privacy → Data deletion.

In-app deletion options

Remove this device data

This removes TwitchMiniChat data from the current Android device and removes this device from server notification registration.

This option does not delete shared server profile data such as uploaded PCG Dex lists or OAuth/login data. Other devices keep their local app data.

Remove this device and server profile data

This removes TwitchMiniChat data from the current Android device and asks the server to delete app-related data for the profiles saved on this device, where available.

This may include push notification registrations, uploaded PCG Dex data, stored app-related profile mappings, and OAuth/login data used by TwitchMiniChat.

Other devices keep their local app storage, but server profile deletion may cause those profiles to be logged out or require syncing again.

How to request deletion manually

Email: unouidol.interactive@gmail.com

Please include

  • Your Twitch username
  • Any relevant profile or account identifiers, if known
  • A short statement that you are requesting deletion of app-related data

What may be deleted

  • Push registration data
  • Stored app-related profile mappings
  • Uploaded PCG Dex data, where applicable
  • OAuth/login data used by TwitchMiniChat, where applicable
  • Other app-related server-side data associated with your request, where applicable

Retention exceptions

Some limited records may be retained for a short period where reasonably necessary for security, abuse prevention, fraud prevention, moderation review, audit, or legal compliance.

Response timing

Deletion requests are reviewed and processed within a reasonable timeframe.
