# CLAUDE.md

@AGENTS.md

The imported `AGENTS.md` is the binding specification for work in this
repository. Follow it as written, and prefer it over any general habit or
default when the two disagree.

This file exists only to load it. Claude Code reads `CLAUDE.md` automatically,
while `AGENTS.md` is an ordinary file until something points at it, so without
this import the repository rules were absent from a session unless someone
remembered to ask for them.

Keep this file this short. Every actual rule belongs in `AGENTS.md`, so that the
two documents cannot drift apart or contradict each other.
